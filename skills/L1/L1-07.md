# L1-07 簡報大綱生成

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 需做簡報者 |
| 什麼時候用 | 接到簡報任務時 |
| 貼什麼進去 | 相關資料或一段口述需求 |
| 產出 | N 頁簡報架構，每頁：標題／要說的一句話／需要的素材 |
| 要改的參數 | ①頁數 ②聽眾是誰 |
| 可否排程 | 否 |
| 對客戶的好處 | 不用對著空白投影片發呆，先有骨架再去找素材，該補數字的地方也標出來了 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我規劃簡報大綱」「這個題目要講幾頁怎麼排」

不屬於本技能的情況：對外客戶提案的架構設計 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
幫我規劃一份 {頁數} 頁的簡報大綱。
聽眾：{誰，以及他們最在意什麼}
目的：{要他們做什麼決定／知道什麼}

每頁輸出三行：
P{n} 標題：
  這頁要傳達的一句話：
  需要準備的素材：（圖表／數據／截圖／案例，具體寫）

規則：
- 第一頁必須是結論，不要用「大綱」「背景介紹」開場
- 需要數據的地方標 {待補數據：___}，不要自己編數字
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 用一個自己真的要做的題目跑
2. 第一頁確實是結論，不是「大綱」
3. 需要數字的地方是 {待補數據}，沒有被編出來
