# L1-11 公告一鍵三版本

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 行政、人資、主管 |
| 什麼時候用 | 要發內部公告時 |
| 貼什麼進去 | 一段口述的公告重點 |
| 產出 | 三版本：正式公文／群組親切版／簡訊 60 字版 |
| 要改的參數 | ①生效日期 |
| 可否排程 | 否 |
| 對客戶的好處 | 一次寫好公文、群組、簡訊三種版本，不用改三遍，也不會三個版本說法不一致 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我寫公告」「這個要通知全公司」「群組版跟公文版都要」

不屬於本技能的情況：對外客戶函文、新聞稿 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
把以下重點寫成內部公告，輸出三個版本：
【A 正式版】公文體，含主旨、說明、生效日
【B 群組版】口語、親切，3～5 行
【C 簡訊版】60 字內，只留「什麼時候、要做什麼」

生效日期：{日期}
規則：三版本的事實內容必須一致；重點裡沒提到的細節不得補寫，缺的寫 {待補}。

---
（貼上重點）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 用一則真的要發的公告跑
2. 三個版本的日期、對象、動作完全一致
3. 沒提到的細節是 {待補}，沒有被補寫
