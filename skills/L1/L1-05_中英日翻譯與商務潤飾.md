# L1-05 中英日翻譯＋商務潤飾

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 有海外往來者 |
| 什麼時候用 | 要寄外文信／看外文文件 |
| 貼什麼進去 | 原文 |
| 產出 | 譯文 + 一行「這樣寫的語氣是」說明 + 語意不清或可能失禮的提醒 |
| 要改的參數 | ①目標語言 ②場合（客戶／供應商／內部） |
| 可否排程 | 否 |
| 對客戶的好處 | 不用等英文好的同事有空，也不會不小心寄出失禮的信 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我翻成英文」「這封日文信在講什麼」「這樣寫會不會不禮貌」

不屬於本技能的情況：原廠手冊、release note 的技術重點整理 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
把以下內容翻成 {英文／日文／繁體中文}，用於 {客戶／供應商／公司內部} 場合。

輸出：
1. 譯文（商務書信體，不要逐字直譯）
2. 一行說明：這個版本的語氣偏正式還是親切、適合什麼關係
3. 如果原文有語意不清或可能失禮的地方，列出來提醒我

規則：專有名詞、公司名、產品名保留原文並在括號附譯名，不要自創譯法。

---
（貼上原文）
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 拿一封真的要寄的信跑一次
2. 專有名詞有保留原文，沒有被自創譯名
3. 語氣說明看得懂，知道這版適不適合對方
