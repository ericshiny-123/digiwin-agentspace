# L1-14 合約／報價單重點與提醒

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 業務、採購、主管 |
| 什麼時候用 | 收到合約或報價單 |
| 貼什麼進去 | 合約／報價單檔案 |
| 產出 | 金額與期限表 + 需要注意的條款清單（附條號）+ 待釐清問題 |
| 要改的參數 | ①我是哪一方（買方／賣方） |
| 可否排程 | 否 |
| 對客戶的好處 | 金額跟期限一目了然，該注意的條款附條號，不會整份看完還漏掉關鍵那一條 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這份合約幫我看重點」「報價單有沒有陷阱」「哪些條款要注意」

不屬於本技能的情況：法律意見、條款是否有效的判斷、一般長文件摘要（請用 L1-04） —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
我是這份文件的 {買方／賣方}。請整理重點。

輸出：
【金額與期限】表格：項目｜金額｜幣別｜期限｜出處條號
【需要注意的條款】只列出對我方有義務或風險的條款，附條號與原文摘錄
【待釐清】文件中語意不明或前後不一致的地方

規則（重要）：
- 這不是法律意見。不得對條款是否合法、是否有效下結論
- 每一條都要附出處條號；找不到條號的不要寫
- 金額一律照抄，不得換算幣別或加總（需要加總時寫出算式）
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 用一份真的合約或報價單跑（金額可先遮蔽）
2. 每一條注意事項都附得出條號
3. 沒有出現「這條無效」「這樣不合法」這類法律結論
