# L1-02 這封信幫我回（三種語氣）

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 收到需要回覆但懶得起頭的信 |
| 貼什麼進去 | 整封來信內容（含往來紀錄） |
| 產出 | 三個版本的回信草稿：正式／親切／簡短，各 150 字內 |
| 要改的參數 | ①我的立場（同意／婉拒／要更多資訊／爭取時間） |
| 可否排程 | 否 |
| 對客戶的好處 | 卡住不知道怎麼開頭的信，30 秒有三個版本可挑，改一改就寄得出去 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這封信幫我回」「幫我擬個回覆」「這樣回會不會太硬」

不屬於本技能的情況：整個收件匣的摘要、客訴或需求信的完整處理建議 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
以下是我收到的信。請幫我擬回覆草稿。

我的立場：{同意／婉拒／需要更多資訊／爭取時間，擇一}
我的身分：{職稱}

輸出三個版本，各不超過 150 字：
【A 正式】對外／對主管
【B 親切】平輩同事
【C 簡短】三句話以內

每個版本結尾附一行「這版適合用在：」說明。
規則：不要承諾信中沒有提到的事；金額、日期若原信沒寫就留 {待填}，不要自己編。

---
（貼上來信）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 貼一封自己真的收到的信，跑一次
2. 三個版本語氣真的不同，且都沒有承諾原信沒提到的事
3. 金額與日期若原信沒寫，確認有留 {待填} 而不是被編出來
