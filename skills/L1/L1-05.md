# L1-05 中英日翻譯＋商務潤飾

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 有海外往來者 |
| 什麼時候用 | 要寄外文信／看外文文件 |
| 貼什麼進去 | 原文 |
| 產出 | 譯文 + 一行「這樣寫的語氣是」說明 + 語意不清或可能失禮的提醒 |
| 要改的參數 | ①目標語言 ②場合（客戶／供應商／內部） |
| 可否排程 | 否 |
| 對客戶的好處 | 不用等英文好的同事有空，也不會不小心寄出失禮的信 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我翻成英文」「這封日文信在講什麼」「這樣寫會不會不禮貌」

不屬於本技能的情況：原廠手冊、release note 的技術重點整理 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
把以下內容翻成 {英文／日文／繁體中文}，用於 {客戶／供應商／公司內部} 場合。

輸出：
1. 譯文（商務書信體，不要逐字直譯）
2. 一行說明：這個版本的語氣偏正式還是親切、適合什麼關係
3. 如果原文有語意不清或可能失禮的地方，列出來提醒我

規則：專有名詞、公司名、產品名保留原文並在括號附譯名，不要自創譯法。

---
（貼上原文）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 拿一封真的要寄的信跑一次
2. 專有名詞有保留原文，沒有被自創譯名
3. 語氣說明看得懂，知道這版適不適合對方
