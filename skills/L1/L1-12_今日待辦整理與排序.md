# L1-12 今日待辦整理與排序

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 每天上班後自動跑（建議 09:00） |
| 貼什麼進去 | 無需貼——排程讀取個人待辦 |
| 產出 | 今日清單：逾期／今日必做 3 件／可做／可延後，含逾期天數 |
| 要改的參數 | ①時間（09:00）②排序偏好（期限優先／主管交辦優先） |
| 可否排程 | 是（每日） |
| 對客戶的好處 | 逾期的事會自己跳出來，不用等到被催才發現 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「今天要做什麼」「有沒有逾期的」「幫我排今天的優先順序」

不屬於本技能的情況：從郵件中抽出待辦（L1-01 已包含） —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
讀取我的個人待辦，整理成今日清單。

排序偏好：{期限優先／主管交辦優先}

輸出：
【逾期】期限已過的，最前面，標示逾期天數
【今日必做】最多 3 件
【今日可做】
【可延後】附建議延到哪一天

規則：
- 日期計算不得心算，以系統日期為準逐一比對
- 沒有期限的項目歸「今日可做」，並標「無期限」
- 不要幫我刪除或合併任何待辦
```

## 全域規則（每次執行都適用）

- **只讀取本卡明確授權的來源**（郵件中心、個人待辦）：不另外搜尋我的記憶、檔案總管或知識庫，
  也不執行任何查詢平台資料庫或檔案系統的指令。授權來源取不到資料時直接說「查無」，
  **不要改用其他方式去找**。
- **只在交付產出時寫入**（把摘要寄到信箱、或新增一則彙整用的待辦）；
  **絕不修改、關閉或刪除任何既有的待辦、郵件或平台紀錄**。整理、排序、分類的結果只呈現在
  產出內容裡，不要回頭去改原始項目。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 排程設定注意

- 產出必須推到個人待辦或寄到信箱。
- 設定當下揭露每月預估點數並教客戶怎麼關。


## 5 分鐘檢核（交付現場用）

1. 手動觸發一次，確認逾期天數算得對
2. 沒有待辦被擅自合併或刪除
3. 無期限項目有被標「無期限」
