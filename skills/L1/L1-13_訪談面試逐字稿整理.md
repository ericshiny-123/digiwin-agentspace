# L1-13 訪談／面試逐字稿整理

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 人資、主管、業務 |
| 什麼時候用 | 面試或客戶訪談後 |
| 貼什麼進去 | 錄音或逐字稿 |
| 產出 | 重點摘要 + 依評分面向的原話引用 + 3 個待追問問題 |
| 要改的參數 | ①評分面向（3～5 個） |
| 可否排程 | 否 |
| 對客戶的好處 | 從憑印象評人變成憑原話評人，事後主管要看也有據可查 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「面試整理一下」「這場訪談的重點」「依這幾個面向幫我看」

不屬於本技能的情況：一般會議的決議與待辦整理 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
以下是一場 {面試／客戶訪談} 的逐字稿。

評分面向：{面向1、面向2、面向3}

輸出：
【重點摘要】300 字內
【面向整理】每個面向：受訪者實際講過的原話（引用）｜我的觀察提示
【待追問】3 個這次沒問清楚的問題

規則：
- 「原話引用」必須是逐字稿裡真的出現的句子，不得改寫或綜合
- 不做人格評價、不做錄取建議，只整理事實

---
（貼上逐字稿）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 抽 2 句「原話引用」，回逐字稿找得到一模一樣的句子
2. 沒有出現人格評價或錄取建議
3. 待追問的問題確實是這次沒問到的
