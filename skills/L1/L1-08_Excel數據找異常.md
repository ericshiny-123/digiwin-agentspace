# L1-08 Excel 數據找異常

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 需看報表者 |
| 什麼時候用 | 拿到月報／週報數據時 |
| 貼什麼進去 | Excel／CSV 檔 |
| 產出 | 異常清單（哪一格、異常在哪、可能原因）+ 一句話結論 |
| 要改的參數 | ①什麼算異常（例：月增減 >20%） |
| 可否排程 | 否 |
| 對客戶的好處 | 不用逐格看報表，異常先被圈出來；算式看得到，可以自己驗算 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這張表有沒有怪的地方」「幫我找異常值」「這個數字為什麼變這麼多」

不屬於本技能的情況：對主管或稽核的正式差異說明稿 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
分析這份表格，找出異常值。

異常定義：{例：與上期相比增減超過 20%；或空白、負數、格式不一致}

輸出：
【異常清單】格式：位置（欄／列）｜數值｜為什麼異常｜可能原因（標「推測」）
【一句話結論】這份表最需要被注意的是什麼

規則：
- 計算一律以表格實際數值為準，不得心算或估算；算式要寫出來
- 「可能原因」必須明確標示為推測，不得寫成事實
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 丟一份自己真的在看的表
2. 抽一個異常項自己驗算，算式對得起來
3. 「可能原因」都有標「推測」，沒有被寫成事實
