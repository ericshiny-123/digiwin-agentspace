# L1-08 Excel 數據找異常

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 需看報表者 |
| 什麼時候用 | 拿到月報／週報數據時 |
| 貼什麼進去 | Excel／CSV 檔 |
| 產出 | 異常清單（哪一格、異常在哪、可能原因）+ 一句話結論 |
| 要改的參數 | ①什麼算異常（例：月增減 >20%） |
| 可否排程 | 否 |
| 對客戶的好處 | 不用逐格看報表，異常先被圈出來；算式看得到，可以自己驗算 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這張表有沒有怪的地方」「幫我找異常值」「這個數字為什麼變這麼多」

不屬於本技能的情況：對主管或稽核的正式差異說明稿 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
分析這份表格，找出異常值。

異常定義：{例：與上期相比增減超過 20%；或空白、負數、格式不一致}

輸出：
【異常清單】格式：位置（欄／列）｜數值｜為什麼異常｜可能原因（標「推測」）
【一句話結論】這份表最需要被注意的是什麼

規則：
- 計算一律以表格實際數值為準，不得心算或估算；算式要寫出來
- 「可能原因」必須明確標示為推測，不得寫成事實
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 丟一份自己真的在看的表
2. 抽一個異常項自己驗算，算式對得起來
3. 「可能原因」都有標「推測」，沒有被寫成事實
