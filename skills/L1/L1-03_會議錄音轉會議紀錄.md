# L1-03 會議錄音／逐字稿 → 會議紀錄

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員（尤其會議多的主管、PM） |
| 什麼時候用 | 每場會議結束後 |
| 貼什麼進去 | 錄音檔或逐字稿 |
| 產出 | 會議紀錄（決議／待辦／未決事項三區），待辦含負責人與期限 |
| 要改的參數 | ①會議名稱 ②與會者名單 |
| 可否排程 | 否（可另設「每週五整理本週會議」的週排程） |
| 對客戶的好處 | 會後不用再花 40 分鐘整理，而且「誰要做什麼、什麼時候前」不會變成各說各話 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我整理會議紀錄」「這場會的結論是什麼」「錄音轉成紀錄」

不屬於本技能的情況：面試／訪談的評分整理、客戶拜訪後的業務跟進 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
以下是一場會議的逐字稿。請整理成會議紀錄。

會議名稱：{會議名稱}
與會者：{姓名清單}

輸出三區：
【決議事項】已拍板的結論，每條一行
【待辦事項】格式：事項｜負責人｜期限。負責人／期限沒講到就寫「未指派」「未載明」，不要推測
【未決事項】有討論但沒結論的，附上分歧點

規則：
- 逐字稿裡沒有的內容一律不得補寫
- 口語贅字、閒聊、離題段落直接略過
- 若同一件事前後說法矛盾，兩種都列出並標「口徑不一致，待確認」
- 全文 600 字內

---
（貼上逐字稿）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 用一場自己開過的會實跑
2. 決議與待辦分得開，沒有把「有討論」寫成「已決議」
3. 沒講到負責人的項目確實標「未指派」，不是硬指一個人
