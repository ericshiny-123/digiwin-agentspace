# L1-03 會議錄音／逐字稿 → 會議紀錄

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員（尤其會議多的主管、PM） |
| 什麼時候用 | 每場會議結束後 |
| 貼什麼進去 | 錄音檔或逐字稿 |
| 產出 | 會議紀錄（決議／待辦／未決事項三區），待辦含負責人與期限 |
| 要改的參數 | ①會議名稱 ②與會者名單 |
| 可否排程 | 否（可另設「每週五整理本週會議」的週排程） |
| 對客戶的好處 | 會後不用再花 40 分鐘整理，而且「誰要做什麼、什麼時候前」不會變成各說各話 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「幫我整理會議紀錄」「這場會的結論是什麼」「錄音轉成紀錄」

不屬於本技能的情況：面試／訪談的評分整理、客戶拜訪後的業務跟進 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
以下是一場會議的逐字稿。請整理成會議紀錄。

會議名稱：{會議名稱}
與會者：{姓名清單}

輸出三區：
【決議事項】已拍板的結論，每條一行
【待辦事項】格式：事項｜負責人｜期限。負責人／期限沒講到就寫「未指派」「未載明」，不要推測
【未決事項】有討論但沒結論的，附上分歧點

規則：
- 逐字稿裡沒有的內容一律不得補寫
- 口語贅字、閒聊、離題段落直接略過
- 若同一件事前後說法矛盾，兩種都列出並標「口徑不一致，待確認」
- 全文 600 字內

---
（貼上逐字稿）
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 用一場自己開過的會實跑
2. 決議與待辦分得開，沒有把「有討論」寫成「已決議」
3. 沒講到負責人的項目確實標「未指派」，不是硬指一個人
