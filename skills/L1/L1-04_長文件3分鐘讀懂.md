# L1-04 長文件 3 分鐘讀懂

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 拿到 10 頁以上的 PDF／Word／報告 |
| 貼什麼進去 | 文件檔 |
| 產出 | 一頁式摘要：3 句話結論 + 5 個重點（附出處）+ 3 個我該問的問題 |
| 要改的參數 | ①我讀這份文件的目的（決策／執行／回覆／備查） |
| 可否排程 | 否 |
| 對客戶的好處 | 十頁以上的東西三分鐘知道要不要細看、該追問什麼，不用整份硬讀 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這份太長幫我看重點」「三分鐘告訴我這在講什麼」「這份我要不要細看」

不屬於本技能的情況：合約條款風險整理、Excel 數據異常分析 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
請幫我讀這份文件。我的目的是：{決策／執行／回覆／備查}

輸出：
【三句話結論】這份文件在講什麼、要我做什麼、風險在哪
【五個重點】每點一行，附文件中的頁碼或章節
【三個我該追問的問題】文件沒交代清楚、但會影響我判斷的地方

規則：
- 每個重點都要能對回原文位置，找不到位置的就不要寫
- 不要加入文件以外的背景知識
- 數字一律照抄，不得換算或估算
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 丟一份自己手上真的要讀的文件
2. 隨機抽 2 個重點，回原文找得到對應位置
3. 數字沒有被換算或四捨五入
