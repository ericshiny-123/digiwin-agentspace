# L1-04 長文件 3 分鐘讀懂

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 拿到 10 頁以上的 PDF／Word／報告 |
| 貼什麼進去 | 文件檔 |
| 產出 | 一頁式摘要：3 句話結論 + 5 個重點（附出處）+ 3 個我該問的問題 |
| 要改的參數 | ①我讀這份文件的目的（決策／執行／回覆／備查） |
| 可否排程 | 否 |
| 對客戶的好處 | 十頁以上的東西三分鐘知道要不要細看、該追問什麼，不用整份硬讀 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「這份太長幫我看重點」「三分鐘告訴我這在講什麼」「這份我要不要細看」

不屬於本技能的情況：合約條款風險整理、Excel 數據異常分析 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
請幫我讀這份文件。我的目的是：{決策／執行／回覆／備查}

輸出：
【三句話結論】這份文件在講什麼、要我做什麼、風險在哪
【五個重點】每點一行，附文件中的頁碼或章節
【三個我該追問的問題】文件沒交代清楚、但會影響我判斷的地方

規則：
- 每個重點都要能對回原文位置，找不到位置的就不要寫
- 不要加入文件以外的背景知識
- 數字一律照抄，不得換算或估算
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 丟一份自己手上真的要讀的文件
2. 隨機抽 2 個重點，回原文找得到對應位置
3. 數字沒有被換算或四捨五入
