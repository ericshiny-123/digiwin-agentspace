# L1-12 今日待辦整理與排序

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 每天上班後自動跑（建議 09:00） |
| 貼什麼進去 | 無需貼——排程讀取個人待辦 |
| 產出 | 今日清單：逾期／今日必做 3 件／可做／可延後，含逾期天數 |
| 要改的參數 | ①時間（09:00）②排序偏好（期限優先／主管交辦優先） |
| 可否排程 | 是（每日） |
| 對客戶的好處 | 逾期的事會自己跳出來，不用等到被催才發現 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「今天要做什麼」「有沒有逾期的」「幫我排今天的優先順序」

不屬於本技能的情況：從郵件中抽出待辦（L1-01 已包含） —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
讀取我的個人待辦，整理成今日清單。

排序偏好：{期限優先／主管交辦優先}

輸出：
【逾期】期限已過的，最前面，標示逾期天數
【今日必做】最多 3 件
【今日可做】
【可延後】附建議延到哪一天

規則：
- 日期計算不得心算，以系統日期為準逐一比對
- 沒有期限的項目歸「今日可做」，並標「無期限」
- 不要幫我刪除或合併任何待辦
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。
## 排程設定注意

- 產出必須推到個人待辦或寄到信箱。
- 設定當下揭露每月預估點數並教客戶怎麼關。


## 5 分鐘檢核（交付現場用）

1. 手動觸發一次，確認逾期天數算得對
2. 沒有待辦被擅自合併或刪除
3. 無期限項目有被標「無期限」
