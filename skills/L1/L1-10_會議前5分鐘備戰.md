# L1-10 會議前 5 分鐘備戰

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 開會前 5 分鐘 |
| 貼什麼進去 | 上次會議紀錄 + 本次議程 |
| 產出 | 5 個要點 + 我上次答應的事 + 3 個可能被問到的問題 |
| 要改的參數 | ①我在這場會的角色（報告者／決策者／列席） |
| 可否排程 | 否 |
| 對客戶的好處 | 開會前五分鐘就知道上次答應了什麼、今天可能被問什麼，不會在會議上被問倒 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「等一下要開會幫我抓重點」「上次那場會我答應了什麼」

不屬於本技能的情況：會議結束後的紀錄整理 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
我等一下要開會。我的角色是 {報告者／決策者／列席}。

依據以下上次會議紀錄與本次議程，輸出：
【我上次答應的事】以及現在的狀態（紀錄裡沒寫狀態就標「待我自己補」）
【本次五個要點】
【可能被問到的三個問題】以及各一句話的回答方向

規則：只根據我提供的紀錄，不要補充外部資訊。

---
（貼上上次會議紀錄與本次議程）
```

## 全域規則（每次執行都適用）

- **不得寫入客戶名單、個資、報價金額、圖面與 BOM、內部代號**；使用者若貼入這類內容，
  在產出中以 {已遮蔽} 取代，並於結尾提醒一句。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **找不到依據時明說「查無」**，不得自行推測填補。
- 全程繁體中文（台灣用語）。
- 本技能為唯讀輸出：不寫入任何檔案、不建立待辦、不變更平台紀錄。

## 5 分鐘檢核（交付現場用）

1. 用真的要開的會跑一次
2. 「我上次答應的事」確實出自上次紀錄，沒有被補寫
3. 沒有出現我沒提供的外部資訊
