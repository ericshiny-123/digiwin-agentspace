# L1-10 會議前 5 分鐘備戰

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 全員 |
| 什麼時候用 | 開會前 5 分鐘 |
| 貼什麼進去 | 上次會議紀錄 + 本次議程 |
| 產出 | 5 個要點 + 我上次答應的事 + 3 個可能被問到的問題 |
| 要改的參數 | ①我在這場會的角色（報告者／決策者／列席） |
| 可否排程 | 否 |
| 對客戶的好處 | 開會前五分鐘就知道上次答應了什麼、今天可能被問什麼，不會在會議上被問倒 |

## 任務辨識

使用者出現下列意圖時啟用本技能：「等一下要開會幫我抓重點」「上次那場會我答應了什麼」

不屬於本技能的情況：會議結束後的紀錄整理 —— 請改用對應的其他卡，不要勉強套用本卡格式。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
我等一下要開會。我的角色是 {報告者／決策者／列席}。

依據以下上次會議紀錄與本次議程，輸出：
【我上次答應的事】以及現在的狀態（紀錄裡沒寫狀態就標「待我自己補」）
【本次五個要點】
【可能被問到的三個問題】以及各一句話的回答方向

規則：只根據我提供的紀錄，不要補充外部資訊。

---
（貼上上次會議紀錄與本次議程）
```

## 全域規則（每次執行都適用）

- **只使用使用者在本次對話中提供的內容**：不主動搜尋郵件中心、我的記憶、檔案總管、知識庫或
  個人待辦，也不執行任何查詢平台資料庫或檔案系統的指令。遇到不認識的公司名、人名或專案名，
  一律當成使用者提供的既定資訊直接使用，**不要去查**；資料不足就標 {待補}。
- **本技能為唯讀輸出**：不新增或修改待辦、不寫入檔案、不變更平台紀錄、不寄送任何郵件。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：合約條款、SLA 數字、可用率、法規條號、價格、日期，
  沒有依據就寫「查無」或標 {待補}，不得以業界慣例或常見數字填補。
- 算式用純文字寫（例如 19 / 66 = 28.8%），不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。
## 5 分鐘檢核（交付現場用）

1. 用真的要開的會跑一次
2. 「我上次答應的事」確實出自上次紀錄，沒有被補寫
3. 沒有出現我沒提供的外部資訊
