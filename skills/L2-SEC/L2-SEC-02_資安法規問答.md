# L2-SEC-02 資安法規問答

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 法遵、資安人員 |
| 什麼時候用 | 不定期（想了解法規義務時） |
| 貼什麼進去 | 想了解的議題（一句話即可） |
| 產出 | 適用法規條號＋要求事項＋常見缺口 |
| 要改的參數 | ①我們公司屬於哪個產業別 ②員工人數（可選） |
| 可否排程 | 否 |
| 對客戶的好處 | 答案有條號可查、查不到會明說查不到，不會拿到一個聽起來很篤定但其實是錯的答案 |

> ⚠️ **建置前準備**：本卡需在建置時掛上「法規遵循專家」知識庫，否則無法查到條號與施行狀態，
> 只能給一般性常識回答，請在 5 分鐘檢核前先確認知識庫已掛載。

## 任務辨識

使用者出現下列意圖時啟用本技能：「我們有哪些法規義務」「這個要符合哪些法規」「資安法規問答」「我們公司需要做什麼合規」

不屬於本技能的情況：已發生資安事件、需要判定通報時限（請改用 L2-SEC-03，時效性不同，不要套用本卡格式）。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
我們公司屬於 {產業別}，員工約 {人數} 人。
我想知道關於 {議題} 我們有哪些法規義務。

輸出：
【適用法規】法規名稱｜條號｜施行狀態（現行／已廢止／尚未施行）
【要求事項】逐條白話說明
【常見缺口】這類公司最常沒做到的三件事

規則：
- 每一條都必須附條號；查不到就寫「查無明確依據」，不得推測
- 必須標示法規的施行狀態，尤其注意已廢止與尚未施行的條文
- 本回答為初步整理，正式合規判斷須由法遵人員或律師覆核
```

## 全域規則（每次執行都適用）

- **只讀取本卡明確授權的來源**（知識庫中的法規遵循專家內容，以及使用者貼入的議題描述）：
  不另外搜尋我的記憶、檔案總管或其他知識庫，也不執行任何查詢平台資料庫或檔案系統的指令。
  授權來源取不到資料時直接說「查無明確依據」，**不要改用其他方式去找**。
- **本卡不寫入任何平台紀錄**；絕不修改、關閉或刪除任何既有的待辦、郵件或平台紀錄。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：法規條號、施行狀態、罰則金額，沒有依據就寫「查無」，
  不得以業界慣例或常見數字填補。
- 算式用純文字寫，不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。

## 5 分鐘檢核（交付現場用）

1. 問一個知識庫裡有答案的議題，確認每條都附條號
2. 問一個知識庫查不到的議題，確認誠實回「查無明確依據」而不是瞎掰
3. 確認回覆有出現「須由法遵人員或律師覆核」的提醒
