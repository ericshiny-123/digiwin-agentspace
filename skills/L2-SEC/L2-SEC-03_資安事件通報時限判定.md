# L2-SEC-03 資安事件通報時限判定

## 這張卡是什麼

| 欄位 | 內容 |
|---|---|
| 誰用 | 資安人員 |
| 什麼時候用 | 資安事件發生時（越快用越好） |
| 貼什麼進去 | 事件發現時間＋事件概述＋我們的產業別 |
| 產出 | 適用的通報義務＋各自的法定時限與截止時點＋現在該做的三件事 |
| 要改的參數 | 無額外參數，資訊都在貼入內容裡 |
| 可否排程 | 否 |
| 對客戶的好處 | 出事的當下最慌，這張卡把「幾點前要通報誰」算清楚，不會錯過法定時限而挨罰 |

> ⚠️ **建置前準備**：同 L2-SEC-02，需掛「法規遵循專家」知識庫才查得到條號與時限。

## 任務辨識

使用者出現下列意圖時啟用本技能：「發生資安事件要通報誰」「幾點前要通報」「這個事件要不要通報主管機關」「資安事件通報時限」

不屬於本技能的情況：沒有具體事件、只是想了解一般法規義務（請改用 L2-SEC-02）。

## 提示詞本體（直接套用，{} 內為要改的參數）

```
發生資安事件，請判定通報義務。

發現時間：{YYYY-MM-DD HH:MM}
事件概述：{一段描述}
我們的產業別：{產業別}

輸出：
【適用通報義務】法規｜條號｜通報對象｜法定時限
【截止時點】逐項列出實際截止的日期時間
【現在該做的三件事】

規則：
- 時限計算一律用日期計算工具，不得心算；並註明計算起算點
- 「通報主管機關」與「通知當事人」是不同義務，必須分開列
- 找不到明確法源的通報義務不得列出
- 查不到對應法源時，直接寫「查無明確通報義務，建議仍依內部事件處理程序通報主管」，
  不得推測一個時限給使用者
```

## 全域規則（每次執行都適用）

- **只讀取本卡明確授權的來源**（使用者貼入的事件描述，以及知識庫中的法規遵循專家內容）：
  不另外搜尋我的記憶、檔案總管或其他知識庫，也不執行任何查詢平台資料庫或檔案系統的指令。
  授權來源取不到資料時直接說「查無明確依據」，**不要改用其他方式去找**。
- **本卡不寫入任何平台紀錄**；絕不修改、關閉或刪除任何既有的待辦、郵件或平台紀錄。
- **不得把客戶名單、個資、報價金額、圖面與 BOM、內部代號帶進對外文件**；但使用者自己貼進來、
  或本技能依授權讀取的內容，在本次產出中**照原文呈現，不要遮蔽**——遮蔽會讓產出失去可用性。
  要不要去識別化，由使用者在對外發送前自行判斷。
- **產出一律視為草稿**，對外發送或正式使用前必須由人覆核。
- **原文沒寫的事實不得出現在產出裡**：法規條號、時限天數、通報對象，沒有依據就寫「查無」，
  不得以業界慣例或常見做法填補。
- 算式用純文字寫，不要使用 LaTeX 或數學排版。
- 全程繁體中文（台灣用語）。

## 5 分鐘檢核（交付現場用）

1. 貼入一個測試事件，確認截止時點是用日期工具算出來的且有標起算點
2. 確認「通報主管機關」與「通知當事人」有分開列，不是混在一起
3. 貼入一個知識庫查不到對應義務的情境，確認誠實回查無而非編造時限
