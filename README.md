## skills/ — 技能原始檔

**這裡是改版的單一來源**：每張卡與已部署到 Edge 平台（內測租戶 99998888）的 SKILL.md
逐字（SHA-256）一致。要改技能，改這裡，再同步上平台。

檔名即技能名稱（`L1-01_晨間信件摘要與待辦抽取.md`，與平台上的顯示名稱、frontmatter `name:` 三者一致），
每張的固定結構：

1. **這張卡是什麼** — 誰用／什麼時候用／貼什麼進去／產出／要改的參數／可否排程／對客戶的好處
2. **任務辨識** — 觸發語句，以及「不屬於本技能的情況 → 請改用 L2-xx」的邊界句
   （實測證實平台會拿這句做路由判斷，L2 上架時沿用同樣寫法）
3. **提示詞本體** — `{}` 內為現場要改的參數
4. **全域規則** — 全庫通用的技術管制與使用守則
5. **5 分鐘檢核** — 交付現場逐條驗收用

## 備份方式

由工作區的 `_系統/scripts/backup_agentspace.sh` 同步；場景庫或技能原始檔異動後執行即更新。

**不含**：`98_機密/` 內容、任何客戶名單。
方法論 md 與簡報 pptx 的客戶名已代稱化為「客戶A～E」，完整版以 Google Drive 原檔為準。
